An entry for the [make.fun](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe) bounty **"Worst Superpower"**: invent the most useless superpower in one line of at most 140 characters.

## The entry

> I can hear what my houseplants are thinking, but only on Tuesdays, and all they ever think about is water.

## How it works

`main.ts` (Node 22, stdlib only, no network, no secrets) scores three candidate superpowers against the judge's five published criteria — genuinely useless, lands as a joke, unexpected, tight and specific, clear on one reading — and writes the winner to `/output/entry.txt`.

Run it locally:

```sh
node main.ts
```
